# Club Management System

A full-stack web application designed to simplify the management of college clubs, events, students, and event registrations. The system provides separate functionalities for students and administrators, making club and event management more organized and efficient.

## 🚀 Features

### 👨‍💼 Admin
- Admin authentication and secure login
- Create and manage clubs
- Create, update, and delete events
- View registered students
- Manage club and event information
- Dashboard for monitoring clubs and events

### 👩‍🎓 Student
- Student registration and login
- View available clubs
- View club details
- Browse upcoming events
- Register for events
- View registered events
- Manage student profile
